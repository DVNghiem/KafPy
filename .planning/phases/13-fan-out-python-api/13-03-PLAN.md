    &self,
    fan_out_id: u64,
    branch_name: &str,
    parent_trace_id: Option<&str>,
    parent_span_id: Option<&str>,

    tracing::info_span!(

        fan_out_id = %fan_out_id,
        branch_name = %branch_name,

<task type="auto">
  <name>Task 2: Create branch spans and inject trace context per branch in worker_loop</name>
  <files>src/worker_pool/worker_loop.rs</files>
  <action>
In `src/worker_pool/worker_loop.rs`, find where fan-out branches are dispatched (where JoinSet is used to spawn sink tasks).

For each branch dispatch, do the following:

1. **Capture parent trace context** from the current ExecutionContext:
```rust
let parent_trace_id = ctx.trace_id.clone();
let parent_span_id = ctx.span_id.clone();
```

2. **Create branch span** using the extension trait:
```rust
let branch_span = Span::kafpy_fanout_branch_span(
    fan_out_id,
    sink.topic.as_str(),
    parent_trace_id.as_deref(),
    parent_span_id.as_deref(),
);
```

3. **Build W3C traceparent header** for this branch (using parent trace_id if present, else generate new):
```rust
let trace_id = parent_trace_id.unwrap_or_else(|| {
    // Generate new trace_id: 32 hex chars
    let bytes: [u8; 16] = rand::random();
    hex::encode(bytes)
});
let span_id_bytes: [u8; 8] = rand::random();
let span_id = hex::encode(span_id_bytes);
let traceparent = format!("00-{}-{}", trace_id, span_id);
// trace_flags = "01" (sampled)

let mut branch_trace_context = std::collections::HashMap::new();
branch_trace_context.insert("trace_id".to_string(), trace_id);
branch_trace_context.insert("span_id".to_string(), span_id);
branch_trace_context.insert("trace_flags".to_string(), "01".to_string());
```

4. **Enter the branch span** and pass trace context to the Python handler:
```rust
let _guard = branch_span.enter();
// branch_trace_context will be injected into message_to_pydict as _trace_context
```

5. **Note**: The `rand` crate may need to be added to `Cargo.toml`. Use `rand::random::<[u8; 16]>()` to generate trace_id. Alternatively, generate trace IDs using `uuid::Uuid::new_v4().to_string().replace("-", "")` if uuid is already available.

The branch span is active during the sink task — when the sink task yields (await), the span remains active on the Tokio task.

**Key constraint**: The same trace_id is propagated to all branches of a fan-out dispatch (D-09). Only the span_id differs per branch.

Do NOT create the span if no tracing subscriber is configured — `tracing::info_span!` is zero-cost in that case.

**Locate the dispatch point**: Search for `JoinSet` or `fan_out` in worker_loop.rs to find where branches are spawned.
